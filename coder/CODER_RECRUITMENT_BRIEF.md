# Independent Coder Recruitment Brief

## Project Overview

We are conducting an independent coding exercise for an academic research project on LLM-based audit research. The study examines how different retrieval designs, including text retrieval and XBRL-based relational retrieval, affect the evidence basis of LLM-generated audit-research claims. The goal of this coding task is not to evaluate whether an LLM is generally good or bad at auditing. Instead, the task is to assess whether individual LLM-generated claims are supported by the specific text and structured XBRL evidence that was provided to the model.

Independent coding is important because the paper proposes a claim-level measurement protocol for evaluating retrieval-augmented LLM outputs. We need external coders to apply the protocol to a fixed sample of claims so that we can assess whether the coding categories are understandable, consistently applicable, and suitable for research use. Coders will review each claim, inspect the provided retrieval context and source references, and enter structured codes in a spreadsheet. The work is judgment-based but bounded: coders should rely only on the materials provided and should not conduct external research or use outside company knowledge.

## Task Requirements

- Review the coder instructions, coding protocol, and short codebook before beginning.
- Code 120 LLM-generated claims using the assigned coding form.
- For each claim, compare the claim against the provided retrieval context, source IDs, and LLM output text.
- Enter codes for claim segmentation, claim type, evidence-use type, text support, XBRL graph validity, integrated text-XBRL correctness, audit-boundary notes, and confidence.
- Use only the provided materials; do not search the internet or rely on outside company knowledge.
- Add short notes when a claim is ambiguous, partially supported, or requires audit judgment beyond the provided evidence.
- Return only the completed assigned coding form.

## Preferred Qualifications

- Familiarity with accounting, auditing, financial reporting, or audit research.
- Ability to read SEC filing excerpts and basic structured financial-reporting evidence.
- Careful attention to source support, evidence boundaries, and distinction between factual claims and audit-risk inferences.
- No programming experience is required.

## Estimated Time

- Orientation to instructions and codebook: 20-30 minutes.
- Coding 120 claims: approximately 3-5 hours, depending on familiarity with audit evidence and XBRL terminology.
- Total expected time: approximately 4-6 hours.

## Deliverable

The deliverable is one completed coding form. The researcher will merge the two independent coder forms and calculate agreement/reliability statistics.
