# Author README For Independent Coding Package

## Purpose

This README is for the author/researcher who prepares and distributes the independent coding materials. It is not a coder instruction sheet.

The coding package supports the claim-level validation exercise for the manuscript. It is designed so that each independent coder can receive individual files.

## Files To Send To Each Coder

Send the following shared files to each coder:

1. `CODER_INSTRUCTIONS.md`
2. `CODING_PROTOCOL.md`
3. `CODING_CODEBOOK.md`
4. `independent_coding_sample.csv`
5. `claim_evidence_packet.csv`
6. `coder_coding_form_template.csv`

Ask each coder to make a personal copy of `coder_coding_form_template.csv`, fill in `coder_id`, complete the coding columns, and return the completed file with a coder-specific filename.

Do not send `README.md`, `CODER_PACKAGE_MANIFEST.md`, `independent_coding_results_template.csv`, or `intercoder_reliability_summary_template.md` unless the recipient is helping administer the coding exercise.

## Files Returned By Coders

Each coder should return only their completed coding form.

- Coder 1 returns a completed form with `coder_id = coder1`.
- Coder 2 returns a completed form with `coder_id = coder2`.

After both forms are returned, merge them into `independent_coding_results_template.csv` or into a new combined results file.

## Researcher QA Checklist

Before distribution, confirm:

- `independent_coding_sample.csv` has 120 rows.
- `claim_evidence_packet.csv` has 120 rows.
- `coder_coding_form_template.csv` has 120 rows and blank coding fields.
- The coder-facing files are self-contained and do not require access to the project workspace.

## Scope

The sample includes:

- all 89 hybrid-condition claims;
- 12 LLM-only claims;
- 10 XBRL-only claims;
- 9 text-only claims.

The sample intentionally includes all hybrid-condition claims because the most important validation question is whether claims in a hybrid retrieval condition actually integrate text and XBRL evidence.
