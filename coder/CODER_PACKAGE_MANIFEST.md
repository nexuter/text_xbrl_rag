# Author Manifest For Coder Package

## Purpose

This manifest is for the author/researcher. It records the files prepared for independent coders and the files used later for merging and reliability analysis.

## Coder-Facing Shared Files

| File | Purpose | Rows / Notes |
|---|---|---|
| `CODER_INSTRUCTIONS.md` | Step-by-step coding instructions | Send to both coders |
| `CODING_PROTOCOL.md` | Full independent claim-coding protocol | Send to both coders |
| `CODING_CODEBOOK.md` | Allowed values and short definitions | Send to both coders |
| `independent_coding_sample.csv` | Fixed claim sample | 120 claims |
| `claim_evidence_packet.csv` | Claim evidence packet with retrieval context and LLM output text | 120 claims |
| `coder_coding_form_template.csv` | Blank coding form template | 120 rows |

## Author-Only Files

| File | Purpose |
|---|---|
| `README.md` | Author instructions for distributing files |
| `CODER_PACKAGE_MANIFEST.md` | Author manifest |
| `independent_coding_results_template.csv` | Combined results template |
| `intercoder_reliability_summary_template.md` | Reliability reporting template |

## Return Files

Each coder should return only the completed assigned form. The researcher should merge both completed forms into the combined results template or a renamed combined results file.

## QA Checks

- `independent_coding_sample.csv`: 120 rows.
- `claim_evidence_packet.csv`: 120 rows.
- `coder_coding_form_template.csv`: 120 rows with blank coding columns and blank `coder_id`.
- Completed coder-specific forms should be saved separately after coders return them.
