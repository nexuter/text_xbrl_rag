This step prepares separate figure graphics files in case the journal submission system requires figures to be uploaded separately from the main manuscript DOCX.

## Format Decision

The figures are stored as SVG source files because the diagrams are simple flow/process figures and benefit from scalable vector representation. The figures have also been exported to PNG and PDF because the AAA guide lists PNG and PDF as acceptable figure file formats.

## Reviewer-Relevant Rationale

The figure files separate visual materials from the manuscript text while preserving consistency with the figure captions already included in `submission/AJPT_Main_Manuscript.docx`.

## Remaining Item

If the final submission system specifically requires TIFF or EPS, convert from the SVG or PDF sources before upload. Otherwise, use the PNG files as the default separate figure upload files and retain PDFs as alternatives.
