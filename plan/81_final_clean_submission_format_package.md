## Format Decision

The package follows the separate-file submission strategy:

1. Title page.
2. Main manuscript with table and figure callouts.
3. Separate tables and figures file.
4. Separate online supplement / appendix.
5. Replication package.
6. Cover letter.

An integrated v4 manuscript remains optional, but it is no longer required for submission readiness because the clean package provides clear file naming and navigation.

## Remaining Author-Specific Items

- Submission date.
- Corresponding author details.
- Full author list and affiliations.
- Funding statement.
- Conflict-of-interest statement.
- Final data availability statement adjusted to journal or repository rules.
- Final decision on whether raw SEC downloads are uploaded or represented through public source links, processed artifacts, scripts, and checksums.

## Reviewer-Readiness Assessment

The clean package should reduce reviewer and editor navigation cost. It separates the scholarly manuscript from internal development files, preserves the boundary statements that prevent misclassification as an audit-practice tool or model benchmark, and makes the reproducibility package visible before conversion to `.docx`, `.pdf`, or repository format.
