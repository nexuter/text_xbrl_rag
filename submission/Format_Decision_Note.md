# Format Decision Note

## Decision

The current submission package uses the separate-file format:

1. Main manuscript.
2. Main-text tables and figures.
3. Online supplement / appendix.
4. Replication package.
5. Cover letter and title page.

## Reason

The separate-file format keeps the main manuscript focused on the methodological argument while allowing reviewers to inspect tables, figures, appendix evidence, and replication materials without overloading the main text.

## When To Create An Integrated Manuscript

Create an integrated v4 manuscript only if the journal, editor, or author team later requires a single combined file.
